## 🚀 GitHub Pages Üzerinden Canlıya Alma Adımları

1. **GitHub'da Yeni Repo Oluşturun:**
   - [GitHub](https://github.com/new) sitesine gidin ve örneğin `wa-link` veya `whatsapp` adında yeni bir **Public** repository oluşturun.

2. **Dosyaları Yükleyin:**
   - `whatsapp-redirect` klasörü içindeki tüm dosyaları (`index.html`, `404.html`, `.nojekyll`) yeni oluşturduğunuz reponun içine yükleyin (upload) veya Git ile push edin:
   ```bash
   git init
   git add .
   git commit -m "Add WhatsApp redirect site"
   git branch -M main
   git remote add origin https://github.com/KULLANICI_ADI/REPO_ADI.git
   git push -u origin main
   ```

3. **GitHub Pages'i Etkinleştirin:**
   - GitHub reponuzda **Settings → Pages** sekmesine gidin.
   - **Source** kısmında `Deploy from a branch` seçeneğini ve Branch olarak `main` (`/root`) seçip **Save** butonuna tıklayın.
