2. MESAJ ŞABLONLARINI META'DAN ÇEKME SİSTEMİ (TEMPLATE FETCHING SYSTEM)
================================================================================

[Fonksiyon Tanımı]
  - JavaScript Dosyası: dashboard.js
  - Fonksiyon Adı: fetchMetaTemplatesFromApi()

[API İsteği Yapısı]
  - HTTP Yöntemi: GET
  - Endpoint: https://graph.facebook.com/v20.0/{WABA_ID}/message_templates?limit=100
  - Örnek Gerçek URL: https://graph.facebook.com/v20.0/27800533569587222/message_templates?limit=100
  - Request Headers:
      Authorization: Bearer {ACCESS_TOKEN}
      Content-Type: application/json

[Çalışma Mantığı & Veri İşleme]
  1. Ayarlar sekmesindeki `metaWabaId` ve `metaToken` değerleri okunur.
  2. Meta Graph API'ye GET isteği atılır.
  3. Gelen JSON yanıtında `data` dizisi taranarak her şablonun:
     - Şablon Adı (`tmpl.name`)
     - Dili (`tmpl.language`)
     - Kategorisi (`tmpl.category` -> MARKETING, UTILITY, AUTHENTICATION)
     - Onay Durumu (`tmpl.status` -> APPROVED, REJECTED, PENDING)
     - Şablon Gövde Metni (`components[type='BODY'].text`) ayıklanır.
  4. Şablon içindeki `{{1}}`, `{{2}}` gibi değişkenler Regex ile tespit edilerek dinamik parametre sayısı hesaplanır.
  5. Dashboard üzerindeki şablon seçim menülerine (`#bulkTemplateSelect` ve `#quickTmplSelect`) otomatik eklenir.

--------------------------------------------------------------------------------
A) WEBHOOK DOĞRULAMA (WEBHOOK VERIFICATION - GET /webhook)
--------------------------------------------------------------------------------
Meta Developer Console'da Callback URL kaydedilirken Meta sunucusu bu adrese GET atar:
- GET /webhook?hub.mode=subscribe&hub.verify_token=cleopatra_wh_9f8a7c6b5a4d3e2f1a0b9c8d7e6f5a4b&hub.challenge=1158201484
- Sunucu `hub.verify_token` değerini kontrol eder. Doğru ise HTTP 200 ile `hub.challenge` string'ini aynen döner.

--------------------------------------------------------------------------------
B) GELEN OLAYLARI İŞLEME (INCOMING WEBHOOK EVENT HANDLER - POST /webhook)
--------------------------------------------------------------------------------
Meta sunucuları WhatsApp event'lerini bu endpoint'e POST eder:
1. Gelen Müşteri Mesajı (`value.messages`):
   - Müşterinin telefon numarası (`msg.from`), profil adı (`contacts[].profile.name`), mesaj metni (`msg.text.body`), mesaj ID'si ve zamanı alınır.
   - Yerel mesaj dizisine eklenir ve `webhook-messages.json` dosyasına kaydedilir.
2. Mesaj Durum Güncellemeleri (`value.statuses`):
   - Mesajın iletim durumu (`sent`, `delivered`, `read`, `failed`) güncellenir.

--------------------------------------------------------------------------------
C) DASHBOARD ENTEGRASYON İÇİN SUNUCU ENDPOINT'LERİ
--------------------------------------------------------------------------------
- GET  /api/messages?phone=...&since=...  -> Kayıtlı mesajları ve durumlarını Dashboard'a döner.
- POST /api/record_outgoing               -> Dashboard'dan gönderilen mesajı sunucu veritabanına kaydeder.
- POST /api/simulate_incoming             -> Test amaçlı sahte gelen mesaj oluşturur.
- GET  /api/health                        -> Sunucu sağlık durumunu verir.
- GET  /debug                             -> Görsel Webhook canlı test & kontrol panelini sunar.
